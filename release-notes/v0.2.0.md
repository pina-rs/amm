## [0.2.0](https://github.com/pina-rs/amm/releases/tag/v0.2.0) (2026-10-28)

Grouped release for `amm`.

### What's new

#### Choose the most you will pay or the least you will receive

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #34](https://github.com/pina-rs/amm/pull/34)

##### User impact

Swaps, deposits, and withdrawals now require absolute token limits that you choose. The RPC's simulation results can no longer weaken those limits. Replace `--slippage-bps` with `--minimum-out` or `--maximum-in` for swaps, and both `--maximum-amount-0/1` or `--minimum-amount-0/1` values for liquidity. Verify prices independently before choosing your limits; quotes remain advisory.

#### Keep average prices accurate in pools with extreme ratios

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #33](https://github.com/pina-rs/amm/pull/33)

##### User impact

Average prices now retain the entire elapsed price history even when one token is much scarcer than the other. A continuously positive pool price can no longer appear to be zero because its accumulator ran out of room, and swaps continue to settle.

#### The AMM has its permanent mainnet address

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #19](https://github.com/pina-rs/amm/pull/19)

##### User impact

The AMM now lives at `pAMMzVPRwtrxQs2CjLTUUpfCAp9XdvVmwwVhpAuCobi`. Pools, fee tiers, and liquidity tokens are created under this address, so wallets and apps should use the latest clients to find them.

#### Pools can no longer name an empty creator address

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #9](https://github.com/pina-rs/amm/pull/9)

##### User impact

Fees that would have accrued to an address nobody controls are now impossible to create: naming the unset default address as a pool creator fails with `DefaultCreator`, and so does handing an existing pool's creator rights to it.

#### Read RPC failures safely

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #35](https://github.com/pina-rs/amm/pull/35)

##### User impact

RPC errors and failed simulation logs show terminal control characters as visible text, so an endpoint cannot use diagnostics to erase terminal output or manipulate the clipboard. Scripts using `--json` can read command failures as an `error` object on stderr.

#### A slightly cheaper, slightly smaller program

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #15](https://github.com/pina-rs/amm/pull/15)

##### User impact

Swaps, deposits, and withdrawals each cost 10–25 fewer compute units, and the deployed program is about 0.5 KB smaller, which lowers its rent. Every processor now builds the pool PDA's signer through one shared helper instead of a compiled copy per call site. Nothing about the math, fees, or account layout changed.

#### Pools now track their average price over time

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #10](https://github.com/pina-rs/amm/pull/10)

##### User impact

Every market now keeps a running sum of its price over time, and a new permissionless `SyncPool` instruction advances it on demand. Anyone can sample that sum at two moments to compute a time-weighted average price that a single transaction cannot meaningfully move — the standard building block for pricing collateral and rewards. Nothing else about trading changes: swaps cost the same and advance the accumulator themselves.

#### Average prices can no longer be rewritten after the fact

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #18](https://github.com/pina-rs/amm/pull/18)

##### User impact

A pool's time-weighted average price now only counts each price for the time it actually stood. Sending tokens straight into a pool and syncing it can no longer change the average for time that has already passed, so integrations that rely on the average are much harder to manipulate. New fee tiers now announce themselves with an event, and the program publishes its security contact details so researchers can reach the maintainers privately.

#### Safely preview transactions

_Owner:_ [@ifiokjr](https://github.com/ifiokjr) · _Review:_ [PR #32](https://github.com/pina-rs/amm/pull/32)

##### User impact

Quotes and simulation previews no longer send your signature to the RPC service. The service cannot turn a preview into a trade or another action on your behalf.
