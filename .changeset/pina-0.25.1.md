# Update Pina to 0.25.1

Track the Pina 0.25.1 release so the program, CPI crate, clients, CLI and Surfpool tests build against the current framework. Compute units fall 19.9% across the 11 measured instructions (87,868 to 70,376 CU), and 0.25.1 removes most of the binary-size growth 0.25.0 introduced, leaving 216 bytes (+0.23%) over 0.24.0.
